# panel.entry_points module

This module defines a function for iterating over entry points as well
as for loading them. It is copied almost entirely from the entrypoint
handling in the excellent Hypothesis package
[HypothesisWorks/hypothesis](https://github.com/HypothesisWorks/hypothesis).
