# panel.util.parameters module

panel.util.parameters.edit_readonly(parameterized: param.Parameterized) → Iterator
Temporarily set parameters on Parameterized object to readonly=False to
allow editing them.

panel.util.parameters.extract_dependencies(function)
Extract references from a method or function that declares the
references.

panel.util.parameters.get_method_owner(meth)
Returns the instance owning the supplied instancemethod or the class
owning the supplied classmethod.

panel.util.parameters.recursive_parameterized(parameterized: Parameterized, objects=None) → list\[Parameterized\]
Recursively searches a Parameterized object for other Parmeterized
objects.
