# panel.models.deckgl module

Defines a custom DeckGLPlot to render DeckGL Plots

\[Deck.gl\]([https://deck.gl/#/](https://deck.gl/#/)) is an awesome
WebGL-powered framework for visual exploratory data analysis of large
datasets.

And now DeckGL provides Python bindings. See

- \[DeckGL Docs\]([https://deckgl.readthedocs.io/en/latest/](https://deckgl.readthedocs.io/en/latest/))

- \[PyDeck
  Repo\]([uber/deck.gl](https://github.com/uber/deck.gl/tree/master/bindings/pydeck))
